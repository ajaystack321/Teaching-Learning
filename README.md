# B.Ed Learning Website

A simple static learning portal built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish with GitHub Pages
1. Create a GitHub repository named `BED-Learning`.
2. Upload the contents of this folder to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/(root)`, then Save.
6. Wait for deployment and open the published URL shown in Pages.

## Content structure
Subject → Sub-subject → Unit → Chapter → Section

Resource categories: Assignment, Practical, Report, Teaching Practice.
Academic year and session are selectable in the sidebar.

## Notes
This is a starter template. Replace placeholder chapter and section names and descriptions with your official syllabus and learning content. Speech uses the browser's built-in speech synthesis.
